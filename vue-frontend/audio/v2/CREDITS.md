# 回魂夜 audio_v2 · 素材署名与授权

本目录所有音效/环境/配乐均由下列**真实录音**加工而成（裁切、变调、EQ、卷积混响、叠混、响度归一）。没有任何一条是纯振荡器合成。

授权范围只用了 **CC0 / Public Domain / CC BY**（3.0 或 4.0）。CC BY 素材在游戏内“制作人员/致谢”页须按下方“必须署名”一节列出；CC0 与公有领域素材无署名义务，这里照样记录来源以便追溯。未使用 BBC Sound Effects（仅非商用）、freesound（需登录）及任何 NC/SA 素材。

> 例外：`music/bgm_*` 三首是游戏原有配乐（2026-06 由作者选定放入 `vue-frontend/audio/`），仓库里没有记录来源和授权，**上线前请作者补充确认**。本目录只是只读复制并重编码，没有改动原文件。

## 五、加工说明

- 修改声明（CC BY 要求注明是否修改）：上表所有 CC BY 素材均经过裁切、变调、滤波、混响、叠混与响度归一处理。
- 老宅/灵堂/地窖混响：使用自制的卷积脉冲响应（滤波噪声指数衰减 + 早期反射，RT60 约 1.1s / 1.7s / 2.6s），`*_room` 为加混响的室内版本。
- 响度：音效 -16 LUFS（短于 3 秒的按最大瞬时响度计）；环境层与配乐 -18 LUFS；所有文件样本峰值 ≤ -1 dBFS。极短的打击类（骨响、木鱼、确认音）为避免过度压缩而保留了较低的响度，详见 manifest 中 `loudness_measured`。
- 原始下载包保存在 `_raw/`（约 0.8 GB，仅供追溯，**不要部署**）。
