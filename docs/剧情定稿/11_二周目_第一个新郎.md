# 二周目：第一个新郎

> 打出「真名」或「回魂」任一结局后，在标题页解锁「再守一夜」。这一夜你不是孙子，是一九五八年七月十五的爷爷：二十二岁，纸扎匠的徒弟，第一个被按进喜位的新郎。
> 所有节点 id 以 ng_ 开头。背景、立绘全部复用一周目素材。

## ng_01
- 章节: 二周目：第一个新郎
- 场景: 纸扎铺
- 时间: 18:40
- 类型: 普通

正文:
> 一九五八年，七月十五。天还没黑透，铺子里已经点了灯。
>
> 你二十二岁，跟师父学扎纸人第六年。竹篾劈得匀，浆糊熬得稠，一张脸画下来，村里人说比活人还像活人。
>
> 今天的活是莫家的。莫家闺女绣禾，十八岁，上个月没的。她爹托人来说，要配一门亲，纸的就行。
>
> 师父把一沓白纸拍在你面前。“脸要活人的。”他说，“这家规矩，不认画出来的。”
>
> 墙上挂着一面小镜子。镜子里那张脸，二十二岁，黑头发，眼睛有点凹。
>
> 你拿起笔。

## ng_dead2

- 类型: 死亡

- 死亡说明: 纸人不点眼，是怕它认路。你给它点了，它第一个认的，是你。

正文:

>
> 很小的两个点。点完你就后悔了。
>

>
> 然后它笑了。你没有笑。
>
> 师父在门口站着，没有进来。他说：“我说过不点睛。”声音很轻，像在跟一个已经不在的人说话。
>

>
> 天亮以后，村里人见到你，都叫你那个名字。你照镜子。镜子里是一张白纸，眼眶里两个小点，不眨。
